Website Evaluations

This page evaluates two websites using the CRAP design principles: Contrast, Repetition, Alignment, and Proximity.

Coolmath Games - Strong Design Example

  • Contrast: Coolmath Games uses clear contrast between the page background, game thumbnails, buttons, and text. Important navigation options and featured games stand out clearly, which makes the website easier to scan.
  • Repetition: The website repeats consistent card layouts, navigation patterns, colors, and category sections. This repetition helps the site feel organized and makes browsing predictable for users.
  • Alignment: The content is arranged in structured rows and columns. Game titles, images, and category groups line up in a clean way, which makes the page easier to follow.
  • Proximity: Related games, categories, and recommendations are grouped together logically. This helps users find similar content without having to sort through unrelated information.

Arngren Electronics - Challenging Design Example

  • Contrast: Arngren Electronics uses many colors, images, and text elements at the same time. Instead of guiding attention, the competing visuals make the page feel crowded and difficult to read.
  • Repetition: The site does not use many consistent design patterns. Font choices, image sizes, spacing, and layout decisions change throughout the page, which makes the design feel disorganized.
  • Alignment: Many elements appear scattered across the page without a clear grid. The lack of consistent alignment makes it harder to scan the content and understand where to look first.
  • Proximity: Related information is not grouped effectively. Products and descriptions appear close to unrelated items, making it harder to tell which pieces of content belong together.
