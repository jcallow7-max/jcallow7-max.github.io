About

This page is built in part to demonstrate work for ITIS 3135 - Front-End Web Application Development at UNC Charlotte. This course provides students with practical experience in front-end web development through the creation of multiple websites using a variety of tools and techniques.

Throughout the semester, students learn web design, development, validation, deployment, accessibility, and professional workflows while creating several different web projects. These projects help build experience with modern web development tools and best practices.

Tools Used in This Course

  • Visual Studio Code (VS Code)
  • Emmet within VS Code
  • FileZilla for SFTP file transfers
  • Git and GitHub
  • Browser Developer Tools
  • The Accumulus Validator
